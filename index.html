Waypoint

Citation-grounded RAG assistant for NZ immigration policy

Live
  • Designed and built Waypoint, a production-oriented AI application leveraging Retrieval-Augmented Generation (RAG) to answer New Zealand immigration questions from a controlled Immigration New Zealand Operational Manual corpus, combining LLM reasoning with explicit citations, evidence-status handling, and source boundaries to reduce unsupported answers
  • Engineered an AI retrieval pipeline using PostgreSQL, pgvector, OpenAI embeddings, PostgreSQL full-text search and Reciprocal Rank Fusion (RRF), combining semantic and lexical retrieval to provide higher-quality context to the language model rather than relying on vector similarity alone
  • Built an evidence-aware AI decision layer that determines whether retrieved evidence is sufficient, a corpus_gap, or requires an external_source, allowing the LLM to answer only within supported evidence boundaries and surface uncertainty when the corpus is inadequate
  • Implemented the full AI-enabled application stack using FastAPI, async SQLAlchemy, PostgreSQL/pgvector, OpenAI models, React 19, Vite, Tailwind CSS and shadcn/Base UI, with Dockerised services, responsive citation-driven UX, Browse functionality, API integration, security controls and Azure deployment
  • Built a reproducible AI/RAG evaluation workflow instead of relying on subjective prompt testing, auditing the indexed corpus section by section and validating retrieval and answer behaviour against a structured question set, with runtime and evaluation data kept separate and no question-specific tuning
  • Applied production AI engineering practices throughout the project, including deterministic validation around LLM outputs, separation of runtime and evaluation data, regression testing, prompt and retrieval evaluation, source-provenance controls, an ingestion pipeline that fails closed rather than writing structurally incomplete policy text, security-conscious deployment and documented architectural decisions
  • Governed the evidence base itself: the Operational Manual is Crown copyright licensed under Creative Commons Attribution, but the publisher prohibits automated collection, so the corpus is assembled manually and every indexed section records its licence, acquisition method and capture date
